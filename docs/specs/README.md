# Spezifikationen

Eine Spezifikation je Vorhaben: `<name>.md`, Bilder und Vorlagen in `<name>/` daneben. Vorlage:
`Wiesenwischer/works/templates/spezifikation.md`.

Ein Vorhaben startet mit einem Issue „Vorhaben: <Titel>“, das den Pfad der Spezifikation nennt, und dem Label
`spezifiziert`; die Planung startet Marcus mit dem Label `planen`. Braucht das Vorhaben eine Oberfläche, kommt vorher
ein Figma-Entwurf unter `<name>/entwurf/`. Der Plan entsteht unter `docs/plans/<name>.md`. Ablauf:
`Wiesenwischer/works/docs/prozesse/vorhaben.md`.
